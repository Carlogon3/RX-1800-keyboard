# RX-1800-keyboard
A handwired implementation of the MadModLabs 1800 Compact keyboard using a Raspberry Pi Pico and KMK firmware.

> ⚠️ This repository documents my personal implementation. The original keyboard design was created by MadModLabs.

## Features

- Raspberry Pi Pico
- KMK Firmware
- CircuitPython
- Handwired 6×19 matrix
- USB-C breakout (non-functioning at the moment)
- 3D printed case
